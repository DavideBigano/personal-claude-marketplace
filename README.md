# Davide Bigano's Personal Claude Marketplace

A collection of useful skills for Claude Code.

## Plugins

- [Skillmancy](https://github.com/DavideBigano/skillmancy) — Skills for creating, editing, and reviewing Claude Code skills.
- [GitHelpers](https://github.com/DavideBigano/git-helpers) — Skills for managing the project git workflow.
- [OkfWiki](https://github.com/DavideBigano/okf-wiki) — Skills for creating and maintaining Open Knowledge Format bundles.
